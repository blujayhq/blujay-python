# Examples

| File | What it shows |
| --- | --- |
| [send_message.py](send_message.py) | Text someone, then read the message's status |
| [webhook_server.py](webhook_server.py) | Receive webhooks, verify the signature, handle new messages |

Run them from an environment that has `blujay` installed. Guides for every feature are at [docs.blujay.io](https://docs.blujay.io).
